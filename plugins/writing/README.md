# writing

Writing-quality skills.

## Skills

- **anti-ai-writing** — rules distilled from
  [Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing):
  banned vocabulary, constructions, tone, and formatting tells, plus a
  self-edit pass. Loaded before writing any prose a human will read; /foreman
  loads it for all prose its pipeline produces.
